# DailyArc

Anime leveling up application. Level up your real life like an anime protagonist, then share your anime identity card.

## Getting started
Requires Node 24 (the version used so far) and npm.

```
npm install
npm run dev
```

Open http://localhost:3000.

Other commands: `npm run build`, `npm run lint`, `npm run typecheck`, `npm test`.
